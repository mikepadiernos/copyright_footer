# Copyright Footer

Copyright Footer provides a configurable block for adding a translated
copyright notice to a site's footer. It can show an organization name, a year
or year range, and an optional version.

The `4.x` branch supports Drupal 11 and 12.

## Documentation

- [Getting started](getting-started.md) explains installation and where to
  place the block.
- [Block configuration](configuration.md) describes every field and the custom
  format tokens.

For releases and support information, see the
[Drupal.org project page](https://www.drupal.org/project/copyright_footer).
